# Show-o2 DPG Evaluation Pipeline

Evaluate Show-o2 1.5B image generation on BLIP3o-60k DALLE3 prompts, using Qwen3-VL as automated judge. Find which prompts Show-o2 gets wrong.

## Directory Layout

```
Show-o/
  show-o2/                  # Show-o2 source root
    models/
    training/
    transport/
    inference_t2i.py
    configs/
      showo2_1.5b_demo_512x512.yaml
    Wan2.1_VAE.pth          # Download during setup
    pipeline/               # ← THIS FOLDER (put it here)
      run_all.sh
      setup_env.sh
      start_eval_server.sh
      step0_extract_dalle3_prompts.py
      generate_images.py
      generate_images_simple.py
      evaluate_images.py
      analyze_results.py
      dalle3.txt            # Generated by step0
      outputs/              # All outputs go here
```

## GPU Allocation (4x L20 48G)

| GPU | Task | Script |
|-----|------|--------|
| 0 | Qwen3-VL-8B eval server (vLLM) | `start_eval_server.sh` |
| 1 | Show-o2 1.5B gen (shard 0) | `generate_images_simple.py` |
| 2 | Show-o2 1.5B gen (shard 1) | `generate_images_simple.py` |
| 3 | Show-o2 1.5B gen (shard 2) | `generate_images_simple.py` |

## Quick Start

```bash
# 1. Clone Show-o and put this pipeline folder inside show-o2/
git clone https://github.com/showlab/Show-o.git
cp -r pipeline/ Show-o/show-o2/pipeline/
cd Show-o/show-o2/pipeline/

# 2. One-time setup (install deps, download models, extract prompts)
bash setup_env.sh

# 3. Run everything
bash run_all.sh
```

## Step by Step

```bash
cd Show-o/show-o2/pipeline/

# Extract DALLE3 prompts
python step0_extract_dalle3_prompts.py --output dalle3.txt

# Start eval server on GPU 0 (background)
bash start_eval_server.sh &

# Generate images on GPUs 1,2,3
python generate_images_simple.py --gpu-ids 1 2 3 --prompts dalle3.txt

# Evaluate with Qwen3-VL
python evaluate_images.py \
    --results outputs/generated/generation_results.json \
    --output outputs/eval_results.json

# Analyze failures
python analyze_results.py \
    --eval-results outputs/eval_results.json \
    --output-dir outputs/analysis
```

## Key Outputs

| File | What |
|------|------|
| `outputs/analysis/dalle3_failures.txt` | Prompts that Show-o2 got wrong |
| `outputs/analysis/failure_analysis.json` | Failure categories + statistics |
| `outputs/eval_results.json` | Per-image eval (correct/incorrect + reason) |

## Evaluation Criteria

Qwen3-VL judges each image strictly:
- All objects present with correct classes and counts
- Colors match the prompt
- Spatial positions correct
- Photorealistic (no cartoon/sketch/anime)
- Single coherent scene (no collages)

## Failure Categories

| Category | Meaning |
|----------|---------|
| `wrong_count` | Wrong number of objects |
| `wrong_color` | Incorrect colors |
| `wrong_position` | Spatial arrangement errors |
| `missing_object` | Objects missing entirely |
| `not_photorealistic` | Cartoon/sketch output |
| `collage_style` | Multi-panel/grid |
| `wrong_object` | Wrong object type |
| `quality_issue` | Blurry/distorted |
